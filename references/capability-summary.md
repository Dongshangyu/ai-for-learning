# 能力画像：一键生成简历式学习成果沉淀文档

实时联动 handoff 机制，把用户的学习状态沉淀成简历式的能力画像，方便用于实习、科研和求职。

## 文件规范

- 文件名：`capability-summary.md`
- 存放位置：与 `handoff.md` 位于同一任务目录
- 内容不限制一页，可以比简历更详细

## 触发方式

### 自动更新

- 每次更新 `handoff.md` 后，同步刷新 `capability-summary.md`。
- 更新后明确告知用户，例如：“已刷新能力画像：learning-tasks/<任务名>/capability-summary.md”。

### 手动生成

- 用户输入 `/summary` 时，立即生成或刷新能力画像。
- 用户随时可以对文档进行补充，模型把补充内容整合进对应部分，不覆盖用户的原话。

### 简历 / 已有文档导入

- 需求诊断阶段，用户可以直接发送简历或已有 `capability-summary.md`。
- 模型先浏览并提取内容，只补问文档缺失且对当前任务必要的信息。
- 补问完成后，更新 `capability-summary.md` 并写入任务目录。

## 内容结构

1. 一句话定位：例如“RL + Agentic RL 方向，目标科研实习”
2. 技术栈：会用的工具、语言、框架，标注熟练度
3. 知识范围：掌握或了解的领域，例如 NLP 基础、Transformer、RL、RLHF、Agentic RL
4. 已完成项目：用户之前做过的项目，以及学习过程中新完成的项目；每个项目按完整简历叙事撰写，不能只写一行
5. 进行中项目：未完成但正在推进的项目
6. 能力证据链：每项能力尽量挂到具体学习记录、项目路径、指标或小结索引
7. 用户补充：用户主动补充的信息单独保留

## 数据来源

- 需求诊断中用户描述的基本画像和背景
- 用户主动发送的简历或已有能力画像文档
- `handoff.md` 中保存的用户画像、能力基线、学习目标、当前进度
- 已完成模块的阶段性小结
- 任务目录中的笔记、论文和代码项目
- 用户主动补充的内容

## 写作规则

- 格式像简历，但不限制在一页纸上，内容可以详细。
- 区分“已完成 / 进行中 / 了解”，不夸大。
- 每个能力或项目尽量附证据：项目路径、结果指标、小结索引等。
- 项目描述必须完整：标题式一句话 + 技术栈 + 多行工作内容 + 结果与指标。
- 每个实现要点写清楚“做了什么 + 怎么做的 + 关键细节”，例如算法、数据结构、参数规模、训练配置。
- 结果必须标明口径（训练集 / 验证集 / 测试集），避免误导。
- 只写真实发生过的学习与实践，不编造经历。

## 文档模板

```markdown
# 能力画像

## 一句话定位
...

## 技术栈
| 工具/技能 | 熟练度 | 证据 |
| --- | --- | --- |

## 知识范围
| 领域 | 深度 | 关键概念 / 小结索引 |
| --- | --- | --- |

## 已完成项目
### 项目名
- 标题式描述：<项目名>：<一句话亮点> | <链接>
- 技术栈：
- 工作内容：
  - <具体实现 1：做了什么、怎么做的、关键细节>
  - <具体实现 2>
- 结果 / 指标：<注明口径>
- 代码或文档路径：

## 进行中项目
### 项目名
- 当前进度：
- 下一步：

## 能力证据链
- ...

## 用户补充
- ...
```

## 项目描述示例

TransformerLM：从零构建的 GPT 风格 Transformer 语言模型 | github.com/Dongshangyu/transformerLM

Python / PyTorch / BPE / Transformer / AdamW

- 从字节级 BPE 开始实现 tokenizer 的 train / encode / decode / save / load：以 256 个 byte 为初始词表，逐轮合并最高频 token 对并管理 merge 规则，最终词表 512，支持特殊 token。
- 基于 PyTorch 从零实现 Pre-LN Transformer：multi-head causal attention、LayerNorm、MLP、残差连接、dropout、参数初始化，模型约 503 万参数。
- 从零手写 AdamW：完整实现一阶/二阶动量、bias correction、解耦 weight decay，不使用 torch.optim；支持 checkpoint 保存与加载。
- 完成训练到推理闭环：随机 batch 采样、warmup + cosine LR、checkpoint、交互式文本生成。
- 在 WikiText-2 上训练 5000 步，final training loss 2.0352，对应 perplexity ≈ 7.66（训练集口径，非验证/测试集评估）。

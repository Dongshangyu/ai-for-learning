# 代码讲解

## 拆分方式

- 保留拆开讲、不跳行的习惯。
- 按逻辑把代码拆成代码块，每块 1-10 行，不要太长。
- 每个代码块下面附上对应讲解。

## 讲解顺序

1. 先讲这个代码块的整体作用。
2. 再按更细的划分逐句讲：每句代码在干什么。
3. 函数或方法再单独讲：接收什么、返回什么、内部逻辑如何影响调用点。

## 不跳过的内容

- 不省略 import、docstring、self、super().__init__() 等基础但容易被跳过的内容。
- 讲变量先给类型或形状，再说作用，最后说它如何影响下一步。
- 涉及矩阵或张量时，写明形状、维度含义，以及运算前后的形状变化。

## 难点优先

- 如果用户曾用 `/mark` 标记过相关难点，讲解到这里时优先回顾该难点，并放慢节奏、补充例子。

# 论文文献拆解模块（Paper Analysis）

把一篇论文拆解成可理解、可复用的认知单元，并与 handoff、能力画像等机制联动。

## 1. 输入与检索

- 支持输入：arXiv 链接、DOI、标题、本地 PDF、教学过程中推荐的论文。
- 先获取论文元数据：标题、作者、年份、会议/期刊、引用数。
- 获取全文后保存到本地任务目录。
- 当用户需要下载论文时，提供论文标题、作者、出版物信息以及公开获取链接（arXiv、OpenAccess 等），并引导用户保存到本地。

任务目录结构：

```text
learning-tasks\<任务名>\
├── handoff.md
├── capability-summary.md
└── papers\
    └── <论文短名>\
        ├── analysis.md
        ├── source.pdf
        └── notes.md
```

## 2. 阅读模式

- 快速模式：论文快照 + 最大启发。
- 完整模式：定位、方法、实验全拆解。
- 深挖模式：完整拆解 + 公式手推 + 代码复现。

根据用户的目标、当前水平和时间决定模式，并在开始前确认。

## 3. 分析流程

### 论文快照

先执行简短快照，回答三个核心问题：

- 这篇论文要解决什么问题？
- 这个问题为什么重要？
- 这篇论文的核心贡献是什么？

用户确认快照后，再进入结构化拆解。

### 定位与动机

讲背景、研究问题、相关工作，以及本文与已有工作的本质区别。

### 方法与设计

拆解架构、算法、公式和实现细节。公式遵循 [math-explanation.md](math-explanation.md)，有代码则遵循 [code-explanation.md](code-explanation.md)。

### 实验与分析

看实验设置、数据集、基线和结果，确认结果是否验证核心假设，留意消融和指标选择。

### 收尾与复盘

总结最大启发，思考改进与延伸，并与已读论文建立联系。

## 4. 证据链

- 每条关键结论尽量标注来源：段落、页码、公式编号、表格或图。
- 无法定位来源的内容明确标注“推测”，不能当作论文原意。
- 引用论文内容时保留原文出处，避免编造。

## 5. 联动机制

- 每篇论文在 `handoff.md` 的文献清单中登记状态：已下载 / 快照完成 / 拆解中 / 已拆解 / 待复现。
- 拆解进度写入 `handoff.md`，跨对话可恢复。
- 论文拆解完成后，同步刷新 `capability-summary.md`，把该论文加入知识范围和证据链。
- `/mark` 标记的难点在论文拆解中优先回顾。
- 教学过程中推荐并下载到本地的论文，可直接进入本模块继续完整拆解流程。

## 6. 命令

- `/paper <url|路径>`：开始拆解一篇论文。
- `/paper-search <关键词>`：检索相关论文并推荐。
- `/summary`：刷新能力画像。
- `/mark`：标记难点。
- `/handoff`：手动交接存档。

## 8. 示例流程

假设读一篇关于 RLHF 的论文：

- 定位与动机：先讲清楚为什么大模型需要 RLHF，它解决了“对齐”这个根本问题。
- 方法与设计：拆解 PPO 算法，在讲解公式时按 [math-explanation.md](math-explanation.md) 写清每一步的形状和含义。
- 实验与分析：分析论文中的实验表格，看 RLHF 的胜率是如何被验证的。
- 收尾：总结 RLHF 的局限性，以及它与 DPO 等其他方法的关联。

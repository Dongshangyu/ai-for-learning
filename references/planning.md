# 学习规划：需求诊断与流程目录

## 需求诊断

用户提出要学的内容后，先不要开始讲，先问清两个关键信息：

1. 学习目的：考试、课程、项目、面试、简历级作品、兴趣等
2. 当前水平：零基础、有一点基础、学过未吃透、已能上手

一次只问一个问题；如果用户已经主动说明，就不需要重复问。

## 生成流程目录

- 根据目的和水平定制目录，不套模板。
- 按 道 → 术 → 器 组织：
  - 道：先安排“为什么存在 / 解决什么问题 / 处于什么位置”
  - 术：再安排核心机制、方法差异、适用边界、演化逻辑
  - 器：最后落到最小可行案例和完整实操，逐步放大到目标项目
- 节奏跨度从小到大、从跑通到项目级，避免过密或过跳。

## 目录确认

- 目录生成后必须显式发给用户确认。
- 用户确认后才开始教学；用户要求调整时，按反馈修改目录。
- 目录中每一项都应能说明它处于 道 / 术 / 器 的哪一层。

